# Harsh Desai Personal Website

This repository contains the source for my personal portfolio website, hosted on GitHub Pages. The site highlights my background, projects, technical skills, experience, and contact information.

## Overview

The website is a lightweight static site built with:
- HTML for page structure
- CSS for styling and responsive layout
- JavaScript for small interactive behaviors

It is designed to be simple, modern, and easy to maintain while presenting my work clearly.

## Project Structure

- `index.html` — main page content and sections
- `css/styles.css` — site styling and layout
- `js/script.js` — interactive behavior and dynamic content
- `assets/` — images, icons, and other static assets

## Features

- Responsive portfolio layout
- About, projects, skills, experience, and contact sections
- Downloadable resume link
- Links to GitHub and LinkedIn
- Hosted via GitHub Pages

## Deployment

This site is deployed through GitHub Pages. Any updates pushed to the main branch are reflected on the live site.
